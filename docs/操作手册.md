# 操作手册

## 一、快速入门

### 1.1 启动系统

```bash
# 终端1：启动后端
python manage.py runserver

# 终端2：启动前端
cd frontend && npm run dev
```

浏览器打开 `http://localhost:5173`，按 F12 切换手机模拟模式。

## 二、用户操作指南

### 2.1 注册账号

1. 打开首页，点击"注册"
2. 选择身份：**我要点餐** 或 **我是商家**
3. 填写昵称、手机号（11位）、密码（至少6位）
4. 点击"注册"，自动登录并跳转到对应首页

### 2.2 登录

1. 输入用户名和密码
2. 点击"登录"
3. 登录成功后按角色进入不同首页：
   - 普通用户 → 菜单首页
   - 商家 → 管理页面

### 2.3 浏览菜单

1. 首页顶部显示分类按钮：全部 / 饮品 / 小吃 / 推荐
2. 点击分类筛选菜品
3. 菜品卡片显示：图片、名称、价格、月销量
4. 点击卡片进入详情页
5. 详情页可调整数量（1-99），点击"加入 ¥xx"添加到购物车

### 2.4 购物车管理

1. 底部导航栏点击"购物车"
2. 显示已添加的菜品列表，支持：
   - **增减数量**：点击 +/- 按钮
   - **删除**：数量减到0自动删除
   - **清空全部**：点击右上角"清空"按钮
3. 底部显示合计金额，点击"结算"提交订单

### 2.5 支付

1. 提交订单后自动跳转支付页
2. 选择支付方式：微信支付 或 支付宝
3. 查看订单金额和订单信息
4. 点击"支付 ¥xx"完成模拟支付
5. 支付结果在页面内联展示：
   - 成功：显示 ✅ 和"支付成功"，可点击"订单"查看
   - 失败：显示重试按钮

### 2.6 查看订单

1. 底部导航栏点击"订单"
2. 按状态筛选：全部 / 待支付 / 备餐中 / 待取餐 / 已完成
3. 待支付订单显示"支付"按钮
4. 点击订单卡片进入详情页
5. 详情页显示：
   - 订单状态图标
   - 商品清单（名称 × 数量）
   - 订单信息（编号、时间、取餐码）

### 2.7 取餐

1. 订单状态为"待取餐"时，详情页显示6位取餐码
2. 到店后向商家出示取餐码
3. **用户端无需操作**，商家输入取餐码确认后订单自动变为"已完成"

### 2.8 个人中心

1. 底部导航栏点击"我的"
2. 查看订单统计卡片（待支付、待取餐数量）
3. 点击"修改昵称"编辑个人信息
4. 点击"退出登录"确认后退出

## 三、商家操作指南

### 3.1 登录

使用商家账号登录，自动跳转到管理页面。

### 3.2 管理首页

管理页面包含三个Tab：

#### 📊 概况 Tab

- **今日数据**：今日订单数、今日收入
- **待处理**：备餐中 / 待取餐 / 待支付 各状态订单数量
- 点击卡片可跳转到订单Tab并自动筛选

#### 📋 订单 Tab

- 按状态筛选：全部 / 待出餐 / 待取餐 / 已完成
- 每张订单卡片显示：订单号、状态标签、菜品明细、金额、时间
- **待出餐订单**：点击"出餐"按钮 → 确认后生成取餐码，状态变为待取餐
- **待取餐订单**：显示取餐码，点击"确认取餐"→ 输入顾客出示的6位取餐码 → 验证通过后订单完成

#### 🍽️ 菜品 Tab

- 显示所有菜品列表（含已下架）
- **上下架**：点击菜品右侧的开关，一键切换
- **编辑**：点击菜品卡片，弹出编辑窗口
  - 修改名称、价格、分类
  - **更换图片**：点击上传区域选择新图片
  - **删除图片**：点击预览区域上的"删除"按钮
  - **删除菜品**：编辑窗口右上角点击"删除"按钮
- **新增菜品**：点击"+ 新增菜品"按钮
  - 填写名称、价格、选择分类
  - 点击上传区域选择菜品图片
  - 点击"确认添加"保存

### 3.3 商家个人中心

1. 底部导航栏点击"我的"
2. 查看今日经营概览（今日订单数、今日收入）
3. 修改昵称
4. 退出登录

## 四、订单状态说明

```
待支付 ──→ 备餐中 ──→ 待取餐 ──→ 已完成
   │                      ↑           ↑
   │                 商家出餐     商家输入
   ↓                                 取餐码
  已取消
```

| 状态 | 含义 | 用户可操作 | 商家可操作 |
|------|------|-----------|-----------|
| 待支付 | 订单已创建，等待付款 | 支付 | 等待 |
| 备餐中 | 已支付成功，商家开始制作 | 查看 | 出餐 |
| 待取餐 | 已出餐，等待顾客到店 | 查看取餐码 | 输入取餐码确认 |
| 已完成 | 已取餐，订单结束 | 查看 | — |
| 已取消 | 超时未支付自动取消 | — | — |

## 五、常见问题

**Q: 登录提示"网络错误，请稍后重试"？**
A: 检查后端是否已启动（`python manage.py runserver`），确认端口8000未被占用。

**Q: 商家统计数据一直为0？**
A: 今日订单数和收入基于当天订单计算，没有新订单时自然为0。创建一笔订单并支付后即可看到变化。

**Q: 上传图片不显示预览？**
A: 选择图片后会自动生成预览。如果未显示，尝试更换图片格式（jpg/png）或缩小图片大小（不超过5MB）。

**Q: 取餐码错误提示？**
A: 商家输入取餐码时请确认与用户订单详情页显示的6位数字一致。输入错误会提示"取餐码错误"。

**Q: 购物车中的菜品突然不见了？**
A: 如果商家将该菜品下架，购物车会自动移除已下架菜品。
