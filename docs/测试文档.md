## 二、测试用例

### 2.1 用户注册

| 用例 | 操作 | 预期结果 |
|------|------|----------|
| TC-001 | 打开前端，点击"注册" | 进入注册页，显示角色选择（我要点餐 / 我是商家） |
| TC-002 | 选择"我要点餐"，填写昵称、手机号、密码，点击注册 | 注册成功，自动登录，跳转到用户菜单首页 |
| TC-003 | 选择"我是商家"，填写信息注册 | 注册成功，自动登录，跳转到商家管理页 |
| TC-004 | 注册已存在的手机号 | 提示错误，注册失败 |
| TC-005 | 不填必填项直接提交 | 表单校验阻止提交 |
