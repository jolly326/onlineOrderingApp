# 在线点餐平台配置文档

## 后端
- 框架：Django 4.2
- 启动：`python manage.py runserver`（在项目根目录执行）
- 地址：http://127.0.0.1:8000/
- 数据库：MySQL `onlineOrder`

## 前端
- 框架：Vue 3 + Vant 4
- 启动：`cd frontend && npm run dev`
- 地址：http://localhost:5173/（F12 手机模拟模式）
