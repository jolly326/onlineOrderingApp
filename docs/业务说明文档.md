## 角色与职责

| 角色 | 职责 |
|------|------|
| **普通用户** | 注册登录、浏览菜单、购物车、下单支付、查看订单、到店出示取餐码取餐 |
| **商家** | 管理菜品（新增、编辑、上下架）、查看订单、更新订单状态（备餐→待取餐）、确认取餐 |

---

## 普通用户业务流程

### 1. 注册登录
- 手机号 + 密码注册，模拟验证码（任意6位数字即通过）
- 手机号 + 密码登录，支持记住密码

### 2. 浏览菜单
- 首页按分类展示菜品（图片、名称、价格、月销量）
- 点击菜品进入详情页，可查看完整信息

### 3. 购物车
- 菜品详情页点击“加入购物车”，可选择数量（1-99）
- 购物车页显示菜品列表，支持：
  - 增减数量（总价实时更新）
  - 删除单个菜品
  - 清空全部
- 同一菜品自动合并数量

### 4. 提交订单
- 购物车点击“去结算” → 确认菜品、总金额、取餐人信息
- 点击“提交订单” → 校验购物车非空 → 生成订单，状态 = 待支付
- 订单号规则：yyMMdd + 8位随机数

### 5. 模拟支付
- 订单确认页跳转支付页，选择微信或支付宝（模拟）
- 点击“确认支付” → 调用模拟支付接口
- 支付成功 → 订单状态变为“待备餐”，跳转订单详情
- 支付失败 → 提示失败，可重试
- 超时规则：订单生成后15分钟内未支付 → 自动取消

### 6. 查看订单
- 订单列表按状态分类展示：待支付、待备餐、待取餐、已完成、已取消
- 点击订单进入详情，显示：订单号、下单时间、菜品明细、总金额、状态、取餐码

### 7. 到店取餐
- 订单状态为“待取餐”时，订单详情页显示取餐码（6位随机码）
- 用户到店后向商家出示取餐码
- 商家在后台输入取餐码确认 → 订单状态变为“已完成”
- 用户端不需要主动操作取餐

---

## 商家业务流程

### 1. 登录
- 独立后台地址，商家账号密码登录

### 2. 菜品管理
- 新增菜品：名称、价格、分类、上传图片
- 编辑菜品：修改上述信息
- 上下架：一键切换，下架后用户端不可见且不可加入购物车

### 3. 订单管理
- 查看所有订单列表（按时间倒序）
- 点击订单查看详情：订单号、用户、菜品明细、总金额、取餐码、状态
- 新订单有视觉高亮提醒（页面刷新或轮询）
- 更新订单状态（按顺序流转，不可逆转）：
  - 用户支付成功后，状态自动变为“待备餐”
  - 商家点击“开始备餐” → 状态变为“待备餐”（同状态，实质是确认接单）
  - 商家备餐完成，点击“出餐” → 状态变为“待取餐”
  - 用户到店，商家输入取餐码确认 → 状态变为“已完成”

---

## 订单状态流转图

```
待支付（用户未支付）
    ↓ 用户支付成功
待备餐（商家确认开始制作）
    ↓ 商家出餐
待取餐（等待用户到店）
    ↓ 商家输入取餐码确认
已完成
```

**终态**：已完成、已取消（取消后可订单不可再操作）

## 关键业务规则

| 规则项 | 说明 |
|--------|------|
| 同一菜品 | 购物车中自动合并数量，不重复显示 |
| 数量限制 | 1-99份 |
| 订单号 | yyMMdd + 8位随机数 |
| 取餐码 | 6位随机码（数字+字母），订单生成时产生 |
| 支付超时 | 15分钟未支付自动取消 |
| 状态流转 | 商家只能按顺序更新，不可逆转（如不能从备餐直接到已完成） |
| 上下架 | 下架菜品不可在用户端展示，不可加入购物车 |
| 购物车内已下架菜品 | 下单时校验并提示用户移除 |
