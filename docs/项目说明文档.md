# 项目说明文档

## 一、项目概述

### 1.1 项目背景
本项目为软件工程课程作业第三阶段（编码实现），开发一个**单商家自营到店取餐在线点餐平台**。参考瑞幸咖啡、喜茶GO等主流微信小程序的业务模式，聚焦移动端Web体验，实现从浏览菜单到取餐的完整业务闭环。

### 1.2 系统定位
- **业务类型**：饮品/快餐类自营到店取餐平台
- **技术形态**：纯移动端Web应用（适配手机浏览器，无需原生APP）
- **核心场景**：用户线上浏览 → 加购下单 → 模拟支付 → 商家备餐 → 用户取餐
- **服务对象**：普通用户（点餐取餐）、商家（管理菜品、处理订单）
- **MVP目标**：100%覆盖需求分析中所有高优先级User Story，实现可运行的最小可行系统

### 2.2 系统不包含的功能

| 功能 | 说明 | 原因 |
|------|------|------|
| 多商家入驻 | 平台仅支持单商家自营 | 作业范围限制 |
| 配送员功能 | 仅支持到店取餐，无配送 | 简化业务逻辑 |
| 优惠券/积分/满减 | 无营销功能 | 非核心需求 |
| 真实第三方支付 | 模拟支付（不接入微信/支付宝） | 需商户资质 |
| 用户评价 | 业务流程中无评价环节 | 业务需求未涉及 |
| 原生APP打包 | 仅Web端，不生成APK | 无需安装，扫码即用 |
| 微信小程序 | 当前为H5网页 | 开发周期限制 |
| 地图/定位 | 不展示配送轨迹 | 仅到店取餐 |

## 四、核心业务流程

### 4.1 用户完整点餐流程
```
登录 → 浏览菜单 → 加入购物车 → 修改数量/删除 → 提交订单 → 模拟支付 → 支付成功 → 查看订单状态 → 到店出示取餐码取餐
```

### 4.2 商家管理流程
```
登录 → 查看待处理订单 → 出餐 → 输入取餐码确认 → 上下架/管理菜品
```

### 4.3 订单状态流转
```
待支付 → （支付） → 备餐中 → （商家出餐） → 待取餐 → （商家输入取餐码） → 已完成
    ↓
（超时15分钟）→ 已取消
```
